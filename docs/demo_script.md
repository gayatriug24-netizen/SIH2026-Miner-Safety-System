# 90-Second Demo Script

1. Open the dashboard in demo mode. Show three workers as SAFE.
2. Click **Simulate Emergency**.
3. Explain that Worker W03 reports a fall + no movement + SOS at Zone N4 while gas/temperature are elevated.
4. Show the dashboard changing W03 to CRITICAL and the active alert appearing.
5. Point to the map and say the control room now has the worker's last-known zone.
6. Click **Deploy Rover** and show the rover state changing to DEPLOYED with target N4.
7. Explain that the rover provides remote visual/environmental information before human entry.
8. Close with: **Detect earlier. Locate faster. Assess safer. Respond smarter.**
